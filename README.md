# TransportCatalogue

Система управления транспортным каталогом с обработкой маршрутов и остановок.

## Возможности

-  Хранение и поиск остановок и маршрутов
-  Расчет географических расстояний
-  Статистика по маршрутам и остановкам
-  Быстрый поиск и фильтрация данных
-  Сериализация и десериализация каталога
-  Поддержка различных форматов данных

## Особенности реализации

- Гео-ориентированная архитектура с оптимизацией для пространственных запросов
- Хранение геоданных с помощью R-деревьев
- Кэширование запросов для ускорения повторных обращений

## Производительность

- Поиск остановок за O(log n)
- Кэширование результатов частых запросов
- Минимизация аллокаций памяти при обработке запросов
